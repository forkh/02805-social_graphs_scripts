## Shared pairwise format

`tables/pairwise_voting_similarity.csv` — one row per unordered MP pair, `mp_id_1 < mp_id_2`, **all** pairs kept.

| column | meaning |
|---|---|
| `mp_id_1`, `mp_id_2` | stable MP key (`MPID%06d`; same as FPSC `mp_id`). Never join on names. |
| `similarity` | matching valid votes / jointly observed valid votes on contested divisions; empty if the pair never overlapped |
| `n_shared_divisions` | the denominator above (jointly observed contested divisions) |
| `n_matching` | the numerator |
| `meets_min_overlap_20/40/60` | `n_shared_divisions` ≥ threshold (main analysis: 40) |
| `party_1`, `party_2`, `same_party` | party at which each MP cast most ballots in the window |

Definitions: valid vote = `Fyri` or `Ímóti` (`Blankt` excluded, absent never counted); contested division = at least one `Fyri` and one `Ímóti`; window = meeting date 2020-07-29 to 2023-05-04.

## Things to know before comparing with speech similarity

* With overlap ≥ 40 only 41 of 66 MPs have any edge; MPs who first vote in 2023 have at most 26 contested divisions in the window, so they never reach 40. Choose the speech/voting overlap thresholds together.
* Voting similarity is strongly bimodal and block-structured; see section 10 of the notebook for how to compare without letting that dominate.

### Which pairwise file should the speech workstream use?

* **Use `tables/temporal/common_pair_sample.csv`.** It contains the pairs of MPs with at least 20 shared contested divisions in the *pooled* speech window; the four shared-schema columns come first (`mp_id_1`, `mp_id_2`, `similarity`, `n_shared_divisions`, with `mp_id_1 < mp_id_2`), and the counts are in `results/temporal/temporal_results.json` under `common_pair_sample`. `similarity` mixes the two parliaments.
* The full pooled table (all pairs, flags for thresholds 20/40/60) is `tables/pairwise_voting_similarity.csv`; the common sample is the `meets_min_overlap_20` subset of it, annotated with per-period shared counts. Per-period tables are in `tables/temporal/`; only a small subset of pairs is eligible in both periods, because the post-election part of the speech window has few contested divisions.
* **Thresholds:** the temporal analysis uses **20** shared contested divisions (largest threshold keeping at least 85 % of the MPs of both the pre- and post-election networks); the baseline notebook's main threshold is 40 (it leaves out MPs who joined after the break). The speech comparison should state its own threshold; 20 is the one used for the common sample.

### Principal limitations

* **No causal claim about the election.** The 91-day period with no recorded division contains the election, the change of government and the winter, so these cannot be separated; the first observed post-election vote is not an event date.
* **Government/opposition is a hypothesis.** The official sources fix the election and government dates only; the coalition parties come from secondary sources, and the community-versus-coalition comparison is exploratory.
* **Composition and behaviour are entangled.** Most change in network-level summaries goes with a different set of MPs; the continuing-MP comparison covers only the MPs with enough overlap in both periods (see `tables/temporal/continuing_mp_funnel.csv`) and its null models ignore time.
* **Thin post-election window for speech.** Only a few dozen contested divisions fall between the election and the end of the speech data, so period-specific voting similarities there are noisy.
* **Agreement is not ideology.** Contested divisions reflect party discipline and roles; party labels are the modal label in each period (one MP changed party); similarity is only defined where two MPs both voted.
